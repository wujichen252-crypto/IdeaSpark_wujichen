## 五、注意事项（执行时随时回看）

1. **不建独立 tool 模块**——所有新编辑器只通过注册表 + 壳组件接入，业务逻辑不进路由层
2. **许可证红线**——引入任何新依赖前先查 LICENSE；tldraw/PPTist/Planka/AFFiNE-backend 已明确排除
3. **不动表结构**——`managed=False`，一切扩展走 `content` 信封 JSON
4. **旧编辑器不受影响**——Excel/PPT/Markdown 仍走原 `update_file` 接口，`/content` 是新增并行通道
5. **每装一个编辑器跑一遍**：`pnpm run typecheck && pnpm run lint && pnpm run test:run` + 构建后检查 chunk 体积
