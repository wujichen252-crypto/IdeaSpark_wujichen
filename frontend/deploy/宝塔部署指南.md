# IdeaSpark 前端项目 - 宝塔面板部署指南

## 📋 部署前准备

1. 宝塔面板已安装 Nginx
2. 已创建网站（可以是纯静态网站）
3. 本地已完成 `npm run build` 生成 `dist` 文件夹

---

## 🚀 宝塔部署步骤

### 步骤 1：上传构建产物

1. 本地执行打包：
```bash
cd frontend
npm run build
```

2. 将生成的 `dist` 文件夹压缩成 `dist.zip`

3. 登录宝塔面板 → 文件 → 进入网站目录（如 `/www/wwwroot/your-domain.com`）

4. **删除** 目录内的默认文件（index.html 等）

5. 上传 `dist.zip` 并解压，确保 `index.html` 在网站根目录

---

### 步骤 2：配置伪静态（关键！解决 404 问题）

宝塔面板提供了图形化的伪静态配置，这是最简单的方案：

#### 方法一：使用预设模板（推荐）

1. 宝塔面板 → 网站 → 选择你的网站 → **设置**

2. 点击 **伪静态** 选项卡

3. 在「请选择伪静态规则」下拉框中选择：**`vue`** 或 **`thinkphp`**

4. 如果选 `vue`，内容应该是：
```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```

5. 点击 **保存**

#### 方法二：手动填写

如果预设没有 `vue` 选项，选择 **自定义**，填入：

```nginx
location / {
    try_files $uri $uri/ /index.html last;
    index index.html;
}

# 静态资源缓存
location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
}

# 不缓存 HTML
location ~* \.html$ {
    expires -1;
    add_header Cache-Control "no-store, no-cache, must-revalidate";
}
```

---

### 步骤 3：重启 Nginx

宝塔面板 → 软件商店 → Nginx → **重启**

或在终端执行：
```bash
/etc/init.d/nginx restart
# 或
systemctl restart nginx
```

## 🔧 常见问题

### 1. 刷新页面还是 404

**原因**：伪静态规则未生效

**解决**：
- 检查伪静态是否正确保存
- 确认重启了 Nginx
- 检查网站配置文件中是否包含：`include /www/server/panel/vhost/rewrite/your-domain.com.conf;`

### 2. 静态资源 404（JS/CSS 加载失败）

**原因**：可能是路径问题

**解决**：
- 检查 `vite.config.ts` 中的 `base` 配置
- 如果是子目录部署（如 `/app/`），需要设置 `base: '/app/'`

### 3. API 请求跨域

**原因**：前端 API 地址配置不正确

**解决**：
- 修改 `.env.production` 中的 `VITE_API_BASE_URL` 为实际后端地址
- 或配置 Nginx 反向代理（见下方进阶配置）

## 📝 进阶配置

### 配置 HTTPS（SSL）

宝塔面板 → 网站 → 设置 → **SSL** → 申请 Let's Encrypt 证书

### 配置反向代理（API 请求）

如果后端也在同一台服务器，可以配置反向代理：

宝塔面板 → 网站 → 设置 → **反向代理**

添加代理：
- 代理名称：`api`
- 目标 URL：`http://localhost:8080`（你的后端端口）
- 发送域名：`$host`

这样前端请求的 `/api` 会被转发到后端服务。

### Nginx 完整配置参考

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /www/wwwroot/your-domain.com;
    index index.html;

    # 关键：Vue Router History 模式支持
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理（可选）
    location /api/ {
        proxy_pass http://localhost:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

## 🎯 一键部署脚本（可选）

如果希望在服务器上直接拉代码构建，可以使用以下脚本：

```bash
#!/bin/bash
# 保存为 deploy.sh，上传到服务器执行

cd /www/wwwroot/your-domain.com

# 拉取最新代码
git pull

# 安装依赖并构建
cd /path/to/your/project/frontend
npm ci
npm run build

# 复制构建产物到网站目录
cp -r dist/* /www/wwwroot/your-domain.com/

# 重启 Nginx
/etc/init.d/nginx restart

echo "部署完成！"
```

## 📂 文件目录示例

部署完成后，宝塔文件管理器中网站目录应该是：

```
/www/wwwroot/your-domain.com/
├── index.html          # 入口 HTML
├── assets/             # 静态资源
│   ├── index-xxx.js
│   ├── index-xxx.css
│   └── ...
├── images/             # 图片资源（如果有）
└── ...
```

**注意**：不要有多层 `dist` 目录，`index.html` 必须在网站根目录。
