# 宝塔面板 9002 端口部署步骤

## ⚠️ 重要提醒

你的前端部署在 **9002 端口**，后端在 **9000 端口**。

需要配置 Nginx 反向代理，让前端能访问后端 API。

---

## 步骤 1：重新打包前端

```bash
cd frontend

# 确保使用新的环境变量
npm run build
```

打包后会生成 `dist` 文件夹。

---

## 步骤 2：上传文件到宝塔

1. 将 `dist` 文件夹**压缩**成 `dist.zip`

2. 登录宝塔面板 → 文件

3. 进入 9002 端口对应的网站目录（可能是以下之一）：
   - `/www/wwwroot/ideaspark-frontend`
   - `/www/wwwroot/你的域名_9002`
   - 或者其他你指定的目录

4. **删除** 目录内所有旧文件

5. 上传 `dist.zip` 并**解压**

6. 确保解压后 `index.html` 直接在网站根目录，像这样：
   ```
   /www/wwwroot/xxx/
   ├── index.html          ✅ 正确
   ├── assets/
   │   ├── index-xxx.js
   │   └── index-xxx.css
   └── ...
   ```

---

## 步骤 3：配置 Nginx（关键！）

宝塔面板 → 网站 → 找到 9002 端口的站点 → **设置** → **配置文件**

将整个 `server { ... }` 块替换为：

```nginx
server {
    listen 9002;
    
    # 修改为你的实际目录
    root /www/wwwroot/ideaspark-frontend;
    index index.html;
    
    # Gzip 压缩
    gzip on;
    gzip_types text/css application/javascript;
    
    # ========== 关键：Vue Router History 模式 ==========
    location / {
        try_files $uri $uri/ /index.html last;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
    
    # ========== 关键：API 反向代理 ==========
    location /api/ {
        proxy_pass http://47.108.232.238:9000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

**注意**：
- 修改 `root` 路径为你实际的网站目录
- `proxy_pass` 后面的 `/` 不能少！

---

## 步骤 4：重启 Nginx

宝塔面板 → 软件商店 → Nginx → **重启**

或在终端执行：
```bash
/etc/init.d/nginx restart
```

---

## 步骤 5：验证部署

| 测试项 | URL | 期望结果 |
|-------|-----|---------|
| 首页 | `http://47.108.232.238:9002/` | 显示首页 |
| 登录页 | `http://47.108.232.238:9002/login` | 显示登录页 |
| 登录页刷新 | 按 F5 | **不 404** |
| API | `http://47.108.232.238:9002/api/` | 返回后端数据 |

## 快速排查

### 还是 404？

1. 检查文件是否上传到正确位置：
   ```bash
   ls -la /www/wwwroot/你的目录/
   # 应该看到 index.html
   ```

2. 检查 Nginx 配置是否生效：
   ```bash
   cat /www/server/panel/vhost/nginx/你的站点.conf
   ```

3. 检查 Nginx 错误日志：
   ```bash
   tail -f /www/server/nginx/logs/error.log
   ```

### 页面白屏/资源加载失败？

按 F12 打开控制台，查看是否有红色报错：
- 如果是 `404` 错误 → 检查 `dist` 文件夹是否完整上传
- 如果是 `MIME type` 错误 → Nginx 配置问题
- 如果是 `CORS` 错误 → API 反向代理没配置好

### API 请求失败？

1. 确保后端 9000 端口正常运行
2. 检查防火墙是否放行 9000 端口
3. 查看 Nginx 错误日志
