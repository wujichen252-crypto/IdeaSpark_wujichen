### 核心发现
- **前端**：154 模块 / 341 依赖边，平均扇出 2.21。视图间零耦合；分层方向健康（不稳定度 store 0.08 → api 0.32 → views 0.74）。

- **后端**：9 个 Django app，app 内分层零违规；函数内延迟导入实践好（accounts/projects 均用其规避加载环）；仍有 3 处模块级 model 导入形成 `projects↔teams`、`projects↔community` 双向依赖；`projects/services.py` 939 行为最重文件。
