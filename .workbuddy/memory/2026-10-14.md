### 发现并修复的 BUG（重要）
- **资产写入乐观锁从未生效**：`services.py` 中 `file.save(update_fields=['type','content','size','updated_by'])` 漏了 `updated_at`。Django 指定 `update_fields` 时只写列出的字段，`auto_now` 不会自动落库 → `_file_version_token()` 基于 `updated_at` 恒定不变 → 过期令牌写入照样返回 200，并发覆盖静默发生。实测确认令牌写入前后不变。
- **修复**：① `update_fields` 补 `updated_at`（含 `update_project_file` 同模型的另一处）；② 令牌改为 `updated_at + 内容 sha256 前12位`——因 MySQL `project_files.updated_at` 为 `timestamp(0)`（无小数秒），纯时间戳无法区分同秒并发写入。
- 修复后实测：令牌 `17:00:16.b70ba01bc60d` → `17:00:19.e84c12dd5295`；过期令牌 **409 正确拒绝**、最新令牌 200。

## 关键约定（长期）
- 前端分层：store(稳定) ← api ← views(易变)；类型枢纽为 `api/types.ts`（扇入最高）。

- **拆视图外抽样式铁律**：当把上帝视图拆成「薄壳 + 子组件」且原 `<style scoped>` 里含子组件才会用到的类（如 `.section-card`、`.n-card__content`）时，**scss 必须去 scoped 全局化**，并把全部选择器 `nest` 进视图根 class（如 `.project-workspace { ... }`）以防止全局泄漏；原 `:deep(X)` 改为普通后代选择器 `X`。否则 scoped 的 scope 属性加在根元素上，子组件拥有不同 scope 属性，后代选择器匹配不到 → 子组件丢样式。
